- **Form Submit:** Success modal with green checkmark animates in

## IMPORTANT REPLIT NOTES

1. Start with Replit's **"HTML, CSS, JS"** template
2. Add all CDN links in `<head>` (Tailwind, Google Fonts, Font Awesome)
3. Use **Unsplash Source URLs** for images (e.g., `https://source.unsplash.com/800x600/?cow,milk,farm`) — no API key needed
4. Keep JavaScript in a separate `script.js` file and link at bottom of `<body>`
5. Keep custom CSS in `style.css` linked in `<head>` after Tailwind CDN
6. Test mobile view using Replit's preview — resize browser window
7. Use HTML `<form>` with `onsubmit` handler for the subscription form (no backend needed yet)
